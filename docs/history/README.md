# history

Records from earlier phases of the project, kept as they were written. File names in them
refer to the layout of the time: the change logs and test reports used to sit in the
repository root, `system_design/` is now `docs/design/`, `board_evidence/` is now `board/`
and `logs/` is now `results/logs/`.

| File | What it is |
|---|---|
| `changelog_code_completion.md`, `test_report.md` | Code-completion pass and its test report |
| `changelog_phase1_3.md`, `test_report_phase1_3.md` | Phases 1 to 3 (tuning, pipelining, verification) and their test report |
| `archive_placeholder.md` | Note from the start of the project, when `archive/` was reserved for the original FPGA audio effects processor. Nothing was ever placed there. |
